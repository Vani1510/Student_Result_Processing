Student Result Processing System

Project Description:-
The Student Result Processing System is a menu-driven Java application developed to automate the calculation and management of student academic records.
The system allows users to enter student details, calculate total and average marks, assign grades based on performance, and store records permanently using file handling.
My project demonstrates practical implementation of Object-Oriented Programming (OOP) concepts and file handling techniques in Java.


Features
-Add new student records
-Calculate total marks automatically
-Compute average marks
-Assign grade based on performance
-Display all students
-Display failed students
-Input validation for marks (0–100)
-Persistent storage using file handling
-Method overloading implemented

Technologies Used
-Java
-File Handling (BufferedReader, BufferedWriter)
-Object-Oriented Programming
-Git & GitHub
-VS Code
